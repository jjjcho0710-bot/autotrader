## 1. 왜 다시 짓는가 — 기존 구조에서 발견된 문제

| # | 증상 | 추정 원인 | 심각도 |
|---|---|---|---|
| 1 | 입구가 4개로 분산 (트레이더 알리미 봇 / 자비스 애널리스트 봇 / 대시보드 웹채팅 / Open WebUI) | 그때그때 채널을 추가만 하고 통합 안 함 | 중 |
| 2 | 감시종목 아닌 임의 종목 문의 시 "알 수 없음" 응답 | 종목 질문 파이프라인이 watchlist 테이블 존재 여부에 의존, 임의 종목은 KIS API 호출 자체가 안 걸림 | 높음 |
| 3 | 텔레그램 보고 내용이 실제 계좌/거래 내역과 다름(거짓 보고) | 보고 문구를 LLM이 자유 생성 — DB 실측값이 아니라 텍스트로 지어냄 | 높음 (신뢰 문제) |
| 4 | 유튜브/URL 학습했다는 내용을 이후 대화에서 기억 못함 | 자막 추출 실패 시 조용히 넘어가거나, 정제본 저장이 실제로 안 됨 | 높음 |
| 5 | 하루 매수매도 0건 발생 | 판단 사이클 실패가 로그 없이 조용히 무시됨 (정상 보류인지 오류인지 구분 불가) | 높음 |
| 6 | "판단"이라던 것이 실제로는 고정 조건(RSI 임계값 등) if-else였고 AI 판단이 개입 안 함 | 판단 레이어와 실행 레이어가 분리되지 않고 룰에 판단인 척 라벨만 붙어있음 | 높음 (설계 근본 문제) |
| 7 | 코인 매매가 계속 손실, 위 5·6번과 결합되어 신뢰 불가 | 위 구조적 결함이 코인 쪽에서 그대로 반복 | 결정: **코인 완전 폐기, 주식만 유지** |

**결론**: 부분 패치로는 한계. 파이프라인(질문/판단/실행/보고)을 구조부터 다시 설계.

## 2. 차세대 설계 원칙

1. **입구는 하나로 통일**: STARK 텔레그램 봇 1개. 웹 대시보드는 같은 백엔드를 보는 뷰로만 유지, Open WebUI는 폐기.
2. **모든 응답은 실데이터 우선**: 잔고·시세·거래내역은 반드시 DB/KIS API 실측값을 먼저 조회 → 그 값을 템플릿에 꽂고, LLM은 해설·분석만 덧붙임. LLM이 숫자를 생성하는 경로를 원천 차단.
3. **임의 종목 질문 항상 응답 가능**: watchlist 여부와 무관하게 모든 종목 질문에 KIS API 실시간 조회 → 분석. 응답 끝에 "감시종목 추가할까요?" 선택지 제공.
4. **판단(AI)과 실행(룰)을 코드 레벨로 분리**:
   - 실행 레이어(불변 안전장치, LLM 개입 금지): 손절 -7%, 급등 시 절반매도, RSI 트레일링 스탑 등
   - 판단 레이어(AI): HOLD/HALF/ALL, 능동 제안, 리서치 — 반드시 실제 모델 호출 로그가 남고, 호출 실패 시 "판단 보류"를 명시적으로 알림 (침묵 금지)
5. **학습은 저장 검증까지 포함**: 자막 추출 실패/성공, 정제본 저장 성공/실패를 모두 로그로 남기고, 실패 시 텔레그램으로 알림. "학습했다"는 보고는 실제 저장 확인 후에만 발생.
6. **모든 사이클은 무언가를 기록한다**: 매매 판단 사이클(장중 주기적 실행)마다 "매수/매도/보류 + 사유"를 반드시 로그·DB에 남김. 0건인 날도 "왜 0건이었는지" 조회 가능해야 함.
7. **코인 매매는 완전 제거**: crypto-trader 서비스, 코인봇, Upbit 키 폐기. 주식(KIS)에 집중.

## 3. 새 아키텍처 (개념도)

```
[STARK 텔레그램 봇] ── 유일한 대화 입구
        │
        ▼
[질문 라우터]
   ├─ 단순 조회(잔고/보유/시세) → DB/KIS API 직접 응답, LLM 미호출
   ├─ 종목 분석 질문 → KIS API 실시간 조회 → LLM(Gemini/Claude) 분석 → 응답
   └─ 전략/판단 필요 → 판단 레이어 호출

[판단 레이어] (AI, 로그 필수)
   - HOLD/HALF/ALL 신호 생성
   - 능동 제안 (11:00/14:00)
   - 실패 시 "판단 보류" 명시적 알림 → 신호 없음

[실행 레이어] (고정 룰, 안전장치, LLM 개입 없음)
   - 손절 -7%, 급등 절반매도, RSI 트레일링 스탑
   - 판단 레이어 신호 수신 시 검증 후 실행

[학습 레이어]
   - URL/영상 자막 추출 → 성공/실패 로그
   - 성공 시 정제본 생성 → DB 저장 확인 → 저장 성공 시에만 "학습완료" 응답

[웹 대시보드] ── 위 백엔드를 보여주는 뷰. 별도 판단 로직 없음.
```
